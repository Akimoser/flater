# Wild Atlas — Работа с сетью

Практическая работа на Flutter. Автор: Лёвушкин Аким Сергеевич, группа П-7-24.

Каталог животных с поиском через API Ninjas, подробной карточкой, фильтром по региону,
историей запросов и избранным, которое доступно после перезапуска и без сети.
Интерфейс русский; названия для поиска и данные API — английские.

## Требования на оценку 5

| Требование | Реализация |
| --- | --- |
| Dio | `lib/src/network.dart`: `AnimalRepository.search`, GET `/v1/animals` |
| Собственный interceptor с токеном | `TokenInterceptor` добавляет `X-Api-Key` |
| pretty_dio_logger | `createDio`: журнал запросов в debug, без секретных заголовков |
| get_it | `lib/src/dependencies.dart`: регистрация сессии, Dio, репозитория и локального хранилища |

Дополнительно используется `shared_preferences` для избранного и истории, но **не для ключа**.
Состояние интерфейса обновляется через `setState`.

## Запуск на Android

Проверенная среда: Flutter 3.47.4 / Dart 3.13.3, JDK 21.
Android-проект создан штатным Flutter-шаблоном: Gradle 9.3.1, AGP 9.1.0, Kotlin 2.4.0.
В основном AndroidManifest добавлено разрешение INTERNET, в том числе для release.

Распакуйте проект в путь без кириллицы, например `C:\MOBILES\flater`.

```powershell
cd C:\MOBILES\flater
flutter pub get
flutter run
```

1. Получите личный ключ на https://api-ninjas.com/profile.
2. Откройте раздел **Доступ**, вставьте ключ и нажмите **Применить ключ**.
3. Откройте **Каталог** и найдите `fox`, `tiger`, `dolphin` или другой вид.
4. Выберите регион, откройте карточку и сохраните её в избранное.

Ключ хранится только в памяти текущего запуска. После закрытия приложения его нужно
ввести заново. Ключ не встроен в APK, не записывается в настройки и не отправляется
на сторонние адреса. Автоматические HTTP-переадресации отключены.
Это учебное клиентское приложение; для публичного продукта общий секрет сервиса
следует хранить на собственном backend, а не раздавать пользователям.

Без ключа можно нажать **Посмотреть учебный пример**. Две встроенные карточки явно
помечены **ДЕМО**. Они не загружаются из API, не скрывают ошибки сети и не заменяют
проверку настоящих запросов. Демо-карточки в избранном также сохраняют маркировку.

## Проверки

```powershell
flutter analyze
flutter test
flutter build apk --debug
```

Тесты в `test/` проверяют заголовок и обновление ключа, запрет постороннего хоста,
пустой ключ и запрос, статусы 401/403/429/500, тайм-аут, отмену, некорректный JSON,
пустую выдачу, безопасность журнала, хранение избранного и навигацию на экране 360×800.
Сетевые unit-тесты используют подменный HTTP-адаптер Dio, а не оплачиваемые вызовы API.

При `Unable to establish loopback connection` в Java на Windows с кириллицей
в пользовательском TEMP можно задать временный каталог только для текущего терминала:

```powershell
New-Item -ItemType Directory -Force C:\MOBILES\flater\.java_tmp
$env:TEMP = 'C:\MOBILES\flater\.java_tmp'
$env:TMP = $env:TEMP
$env:JAVA_TOOL_OPTIONS = '-Djava.io.tmpdir=C:\MOBILES\flater\.java_tmp'
flutter run
```

## Файлы

- `lib/main.dart` — запуск и тема приложения.
- `lib/src/home_page.dart` — каталог, доступ, избранное и карточка вида.
- `lib/src/network.dart` — Dio, interceptor, logger и обработка ошибок.
- `lib/src/dependencies.dart` — контейнер get_it.
- `lib/src/animal.dart` — модель ответа API.
- `lib/src/local_store.dart` — локальные избранное и история.
- `lib/src/demo_data.dart` — явно обозначенные офлайн-примеры.
- `docs/` — отчёт и скриншоты приложения.
